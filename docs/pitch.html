KI-gestützte Vorprüfung eingereichter Dokumente für die öffentliche Verwaltung — damit sich Sachbearbeiter auf das Wesentliche konzentrieren können.

5-Minuten-Pitch · Konzept, Lösung & Ergebnisse

Die Herausforderung

Unvollständige Anträge kosten den Fachbereich Zeit.

1
Viele Anträge werden mit fehlerhaften oder unvollständigen Dokumenten hochgeladen.
2
Das erzeugt Nachforderungen und Rückfragen — und damit Verzögerungen für die Bürger:innen.
3
Jeder Anhang muss manuell vorgeprüft werden: richtiger Typ? alle Pflichtangaben lesbar? — langsam, wiederholend, fehleranfällig.

Knappe Personalkapazität wird durch eine Aufgabe gebunden, die sich automatisieren lässt.

Die Lösung

DocVal prüft Dokumente automatisch vor.

Ein konfigurierbarer, KI-gestützter Dienst, der eingereichte Dokumente klassifiziert, auf Vollständigkeit und Lesbarkeit prüft und die relevanten Daten extrahiert — und das Ergebnis strukturiert zurückmeldet.

🧭

Meldet, blockiert nicht

DocVal liefert ein Urteil — Filtern, Löschen oder Weiterleiten bleibt beim Fachverfahren. Der Mensch entscheidet.

⚙️

Konfigurierbar

Fachaufsichten definieren Dokumenttypen und Regeln in nahezu natürlicher Sprache — ohne Programmierung.

🔒

Datensparsam

Stateless: keine dauerhafte Speicherung von Bürgerdaten. Das Fachverfahren bleibt führendes System.

So funktioniert es

Zweistufige Prüfung in einer klaren Pipeline.

Mein Entwicklungsprozess

KI-gestützter Workflow — von der Idee zum Code.

1
Forschung & Prototyping — Machbarkeit ausloten: erste Technologien testen, das Problem verstehen, groben Überblick verschaffen. Bevor es tief in die Entwicklung geht.
2
Die „Grill"-Session — vage Vorgaben per LLM einem Stresstest unterziehen: die KI hinterfragt, deckt Logiklücken auf und zwingt zur exakten Definition der Anforderungen.
3
PRD verfassen — die Erkenntnisse in ein strukturiertes Product Requirements Document gießen: konkret, was gebaut wird — die Leitplanke.
4
In Issues zerschneiden — Arbeit in winzige, unabhängige „Tracer Bullets" aufteilen: isolierte Tickets im Kanban-Board, von Agenten parallel abarbeitbar.
5
Umsetzung mit KI-Agenten — autonome Agenten arbeiten testgetrieben (TDD): Ticket nehmen → Test schreiben → Code bis grün → committen.

Prinzip: schnelles Modell zum Schreiben von Code, tiefgründigeres Modell für Reviews.
